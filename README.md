# 小提琴制作工具学习资料库

本项目用于系统整理小提琴制作相关工具的购买、选择、分类、使用方法、工作原理和资料来源。

资料会按工具类别分章整理，每一章尽量包含：

- 工具用途
- 工具分类
- 工作原理
- 制琴中的典型使用场景
- 选购标准
- 品牌与型号
- 调校、保养和安全注意事项
- PDF、视频、图片和外部链接索引

## 当前重点

当前优先整理 `01_刨子` 和 `08_磨刀系统`：

1. 先理解刨子的分类。
2. 再理解刨子的切削原理。
3. 然后对应到小提琴制作中的实际场景。
4. 最后整理品牌、型号、价格和购买建议。
5. 建立通用磨刀系统，供刨子、凿子、刀具和刮刀章节引用。
