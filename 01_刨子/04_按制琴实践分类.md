# 按制琴实践分类

从购买和使用角度看，刨子不应该只按“平底、弧底、大小”来理解，更应该按制琴工序来理解。不同工序面对的木材形状、木纹方向、精度要求和去料量不同，因此需要不同刨子。

## 总览

| 制琴工序 | 主要刨子 | 为什么需要 |
| --- | --- | --- |
| 拼合面板、背板 | 长刨、接缝刨、精密平底刨 | 需要得到笔直、严密、可胶合的接缝 |
| 面板外拱 | 中号平底或微弧底指刨、小号指刨 | 云杉较软，需要快速但可控地形成弧面 |
| 面板内侧挖削 | 中号弧底指刨、小号弧底指刨 | 内侧是凹曲面，平底刨无法贴合 |
| 背板外拱 | 中号指刨、小号指刨、刃口极锋利的小块刨 | 枫木硬且常有波纹，容易逆纹撕裂 |
| 背板内侧挖削 | 弧底指刨，多种尺寸配合 | 背板较硬，厚度控制要求高 |
| 琴颈制作 | 小块刨、小号平底指刨、窄刃刨 | 琴颈有长曲线、窄面和过渡面，需要细控 |
| 指板相关修整 | 小块刨、低角块刨、长一点的平底刨 | 需要控制直线、微弧和局部平整度 |
| 边缘和角部 | 小号指刨、小型弧底刨 | 空间小，曲线变化快，需要局部控制 |

## 拼合面板和背板：需要长刨

面板和背板通常由两片木料拼合。胶合前，接缝必须足够平直、严密。如果接缝不平，后面即使胶合成功，也可能影响中线、强度和外观。

这一工序最适合：

- 长刨
- 接缝刨
- 精度较好的平底刨

为什么不用指刨：

指刨太短，无法可靠建立长距离直线基准。它可以修小区域，但不适合决定整条拼缝的平直度。

关键要求：

- 底面要平直。
- 刃口要直而锋利。
- 每次刨削量要薄。
- 需要检查两片木料合拢后的透光和贴合情况。

## 面板外拱：需要中小号指刨

面板通常使用云杉。云杉较轻、较软，但年轮早材和晚材硬度不同，刨削时容易出现软硬变化。

这一工序适合：

- 中号平底指刨
- 微弧底指刨
- 小号指刨

为什么：

面板外拱是从较粗的形状逐步过渡到流畅曲面。中号指刨可以提高去料效率，小号指刨适合靠近边缘、角部和局部过渡。

使用思路：

1. 用较大的指刨去掉高点。
2. 用中号指刨连接弧线。
3. 用小号指刨修局部不顺的区域。
4. 最后配合刮刀和模板检查弧度。

## 面板内侧挖削：需要弧底指刨

面板内侧是凹曲面，平底刨无法自然贴合。此时弧底指刨非常重要。

这一工序适合：

- 中号弧底指刨
- 小号弧底指刨
- 不同弧度的指刨组合

为什么：

内侧挖削既要去料，也要控制厚度。弧底能进入凹面并保持较稳定的切削。不同位置曲率不同，因此常常需要不同尺寸和弧度的刨子配合。

关键要求：

- 经常用厚度规检查。
- 刨削量要薄。
- 不要只凭视觉判断厚度。
- 接近最终厚度时减少刨削，更多依赖刮刀。

## 背板外拱：需要更锋利、更稳的指刨

背板常用枫木。枫木比云杉硬，且可能有明显波纹。波纹枫的木纹方向会频繁变化，容易出现逆纹撕裂。

这一工序适合：

- 中号指刨
- 小号指刨
- 微弧刃的小块刨
- 刃口保持性较好的刨铁

为什么：

背板外拱需要较强去料能力，但又不能撕裂表面。刨铁必须锋利，刨削量要比云杉更小。小号指刨可以在木纹变化复杂的位置更灵活地换方向。

使用思路：

- 优先顺纹刨削。
- 遇到撕裂就改变方向或减小伸出量。
- 使用微弧刃减少两侧刀痕。
- 不要强推钝刃。

## 背板内侧挖削：需要多把弧底指刨

背板内侧同样是凹曲面，但材料通常更硬，厚度变化也非常关键。

这一工序适合：

- 大一点的弧底指刨用于初步去料
- 中号弧底指刨用于建立厚度过渡
- 小号弧底指刨用于局部区域

为什么：

单一尺寸的弧底刨很难覆盖所有区域。大刨效率高但进不了小曲率区域，小刨灵活但效率低。多尺寸组合能兼顾效率和控制。

## 琴颈制作：需要小块刨和小号平底刨

琴颈不是简单的平面，也不是大面积弧面。它包含长向线条、侧面、斜面、手感过渡和局部窄面。

这一工序适合：

- 小块刨
- 小号平底指刨
- 窄刃小刨
- 必要时使用低角块刨处理端面或斜纹

为什么：

琴颈加工要求线条连续、手感顺滑。小块刨比指刨更容易控制较直的面，小号平底指刨则适合处理局部曲面和过渡。窄刃刨可以进入较窄的位置，避免误伤相邻区域。

常见位置：

- 琴颈侧面初步修整
- 琴颈背部曲线过渡
- 根部附近局部修整
- 指板粘接面或附近区域的精修

注意：

琴颈最终手感通常还需要刀、锉、刮刀和砂磨配合。刨子负责建立干净、连续、可控的基础形状。

## 指板相关修整：需要稳定的平底刨

指板本身通常是乌木，硬度很高。指板表面不是绝对平面，而是带有纵向微弧和横向弧度。

这一工序可能用到：

- 小块刨
- 低角块刨
- 较长的平底刨

为什么：

乌木硬，普通钝刃很容易打滑或刮擦。较稳定的平底刨能帮助控制长向线条，但具体指板修整还需要专门讲弧度、弦高和投射关系。

本项目后续可以把指板工具单独扩展为一节。

## 边缘、角部和局部过渡：需要小号指刨

小提琴边缘和角部空间狭窄，曲线变化快。大刨子容易碰到不该切的位置。

这一工序适合：

- 小号平底指刨
- 小号弧底指刨
- 极小号指刨

为什么：

小号刨子去料慢，但控制精细。它适合在边缘附近做局部修正，尤其是连接大弧面和边缘平台时。

## 入门购买顺序建议

如果目标是从制琴实践出发，而不是收藏工具，可以按下面顺序考虑：

1. 一把可靠的平底小块刨：用于小零件、琴颈、局部平面。
2. 一把中号指刨：用于面板、背板外拱的主要修整。
3. 一把中号弧底指刨：用于面板、背板内侧挖削。
4. 一把小号指刨：用于边缘、角部、局部过渡。
5. 一把较长的平底刨或接缝刨：用于拼板接缝。
6. 根据实际制作过程补充特殊尺寸、特殊弧度或更高品质刨铁。
