# 刨子

刨子是小提琴制作中最重要的切削工具之一。它既可以用于平面修整，也可以用于面板、背板弧面和内侧厚度修整。

> 图片资料：真实产品图和使用场景图见 [media/真实图片索引.md](media/真实图片索引.md)。本章中的 SVG 仅作为结构关系示意，真实外观以产品图和实拍图为准。

本章重点回答：

1. 小提琴制作中会用到哪些刨子？
2. 不同刨子的形状和用途有什么区别？
3. 刨子为什么能切削木材？
4. 选购时应该看哪些参数？
5. 哪些品牌和型号值得进一步研究？
