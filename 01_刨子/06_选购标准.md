# 选购标准

购买刨子前，应该先明确它要解决的工序，而不是只看品牌。

建议先阅读 [按制琴实践分类](04_按制琴实践分类.md)，确认自己当前最需要解决的是拼板、面背板、内侧挖削、琴颈，还是边缘细修。不同工序对应的刨子差别很大。

## 关键参数

| 参数 | 说明 | 为什么重要 |
| --- | --- | --- |
| 尺寸 | 刨身长度、刃宽 | 决定适合大面积去料还是局部精修 |
| 底面形状 | 平底、弧底、不同弧度 | 决定能否贴合目标表面 |
| 刨铁钢材 | 碳钢、A2、PM-V11 等 | 影响锋利度、保持性和磨刀难度 |
| 调节方式 | 手动敲调、螺丝调节 | 影响新手调校难度 |
| 刨口大小 | 固定或可调 | 影响排屑和抗撕裂能力 |
| 做工 | 底面平整度、刨铁贴合、结构刚性 | 影响是否容易震刀和卡屑 |
| 可维护性 | 刨铁是否易买、结构是否简单 | 影响长期使用成本 |

## 新手建议

入门不需要一次买齐所有刨子。更合理的顺序是：

1. 一把用于平面和小零件的可靠小块刨。
2. 一把中等尺寸的平底或微弧底指刨。
3. 一把适合内侧挖削的弧底指刨。
4. 根据实际制作过程，再补更小尺寸或特殊弧度的指刨。

## 需要警惕的问题

- 只买最小号指刨，结果去料效率太低。
- 只看价格，忽略刨铁质量和刨身精度。
- 以为贵的刨子不需要磨刀和调校。
- 没有磨刀系统就急着买很多刨子。
- 不区分平底和弧底，导致工具不适合工序。
