# 磨料和磨具分类

磨刀系统可以有很多组合。入门时不必追求完整收藏，先理解每类磨具解决什么问题。

## 水石

水石常见于精细木工和手工刀具维护。

特点：

- 切削速度快。
- 颗粒级别选择多。
- 容易获得很细的刃口。
- 需要泡水或喷水，视具体类型而定。
- 使用后会磨损，需要定期修平。

适合：

- 刨刃
- 凿子
- 制琴刀
- 需要高锋利度的精细切削工具

注意：

水石如果不平，会把刃口和刃背磨弯。磨石修平和磨刀本身同样重要。

## 油石

油石使用油作为润滑介质，磨损相对慢。

特点：

- 稳定耐用。
- 不容易快速凹陷。
- 切削速度通常慢于水石。
- 清洁方式和水石不同，不能随意混用水和油。

适合：

- 日常维护
- 小刀具
- 不想频繁修平磨石的使用者

## 钻石板

钻石板是在金属板上固定金刚石磨粒。

特点：

- 平整度好。
- 切削硬钢速度快。
- 可用于修平水石。
- 粗颗粒钻石板磨痕明显，需要后续细磨。

适合：

- 修正缺口
- 建立主刃角
- 修平水石
- 处理硬质刃具

注意：

钻石板不等于最终抛光。它很适合作为系统中的“平整和快速去料”环节。

## 砂纸系统

砂纸系统通常把砂纸固定在玻璃、石材或平整板材上使用。

特点：

- 入门成本低。
- 容易更换颗粒级别。
- 平整度取决于底板。
- 砂纸消耗较快。

适合：

- 初学练习
- 临时修刃
- 小型刃具
- 还没有购买磨石时过渡使用

关键是底板必须平整，砂纸必须固定牢靠。

## 皮革和研磨膏

皮革通常用于最后抛光和轻微去毛刺。

特点：

- 能提高刃口细腻度。
- 适合制琴刀和小刃具。
- 使用不当会把刃口磨圆。

适合：

- 制琴刀
- 小凿子轻微维护
- 刨刃最后去除细毛刺

注意：

在皮革上抛光时不要把角度抬得过高，也不要用太大压力。皮革有弹性，压力过大容易圆化刃口。

## 颗粒级别的理解

可以把颗粒级别按功能理解：

| 功能 | 用途 |
| --- | --- |
| 粗磨 | 修缺口、改角度、快速去料 |
| 中磨 | 日常恢复刃口、建立可用锋利度 |
| 细磨 | 提高切削质量、减少磨痕 |
| 抛光 | 去除细毛刺、获得更顺滑切削感 |

颗粒数字本身会因品牌和体系不同而不完全等价。比数字更重要的是流程是否连续：粗磨痕要被中磨去掉，中磨痕要被细磨去掉。

## 一句话记忆

磨具没有绝对最好，只有是否平整、是否适合当前去料量、是否能稳定重复。
