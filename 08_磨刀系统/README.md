# 磨刀系统

磨刀系统不是单一工具，而是一组让切削工具保持锋利、稳定和可重复的设备与方法。小提琴制作中的刨子、凿子、制琴刀、刮刀都依赖良好的磨刃状态。

本章重点回答：

1. 为什么制琴工具需要经常磨刃？
2. 水石、油石、钻石板、砂纸系统有什么区别？
3. 一套入门磨刀系统应该包含哪些东西？
4. 刨刃、凿子、制琴刀的磨法有什么不同？
5. 如何判断刃口是否真正锋利？

## 入门配置

如果只做一套基础系统，可以先考虑：

1. 一块中等颗粒磨石或钻石板，用于恢复刃口。
2. 一块细磨石或抛光石，用于提高锋利度。
3. 一块修平工具，用于保持磨石平整。
4. 一个简单磨刀夹具，用于刨刃和凿子的角度训练。
5. 一块皮革和少量研磨膏，用于制琴刀和局部抛光。

不需要一开始购买很多颗粒级别。真正重要的是稳定角度、磨面平整、毛刺去干净。
